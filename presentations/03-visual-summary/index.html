Core update number one: Copilot Fusion. Fusion is an intelligent router. It dynamically breaks tasks apart: fast, economical models handle syntax and unit tests; frontier reasoning models like Claude 3.7 and o1 handle complex architectural refactoring. For our team, this means our internal tools must adopt dynamic model-routing layers rather than hardcoding to a single LLM API.

Core update number three: Rebuilding Git infrastructure. April Leonard revealed that Git's storage engine was re-architected with lockless ref transactions to withstand agent write storms. On the DevOps side, Actions Workflow Lockfiles cryptographically pin third-party actions—protecting our CI supply chain—and Multi-Cloud Runners execute directly inside our AWS VPCs.

Core update number four: Quality and governance. If agents write 40% of code, how do we keep quality high? Code Review Max runs multi-model adversarial reviews across call graphs. Agent Merge automatically fixes merge conflicts and failing CI runs. And Path-Scoped Approvals let us authorize agents to auto-merge safe paths like client generation, while requiring human architect sign-off on domain logic.
